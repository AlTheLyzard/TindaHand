# Profile avatars

All 12 PNGs are faithful crops of the supplied `docs/designs/TindaHand Filipino avatar options sheet.png`. They are not generated illustrations. `node scripts/prepare-profile-avatars.cjs` reproduces the crops using the existing transitive `jimp-compact` tool; no dependency was installed. `src/constants/profile-avatars.ts` owns local asset references and English descriptions, and re-exports the shared picker order from `profile-avatar-ids.ts`. That module also defines the first preset, `avatar-01`, as the consistent Owner default for creation and missing/null display values. Store only the ID. Existing selections are preserved. Operator placeholders retain the generic profile glyph. No camera/gallery/permission flow is involved.

Each original blue disc is centered in a 294 × 294 square, uniformly resized to 320 × 320 and given a soft circular alpha edge. This removes the source sheet's white margins and the old rectangular contain-padding without stretching the person or cropping their head/face. White shirts in avatars 07 and 12 remain part of the illustrations. The shared avatar component also clips and sizes its image consistently at every display size.
