# Design inputs

This folder contains supplied Figma frame exports for authentication, dashboard, inventory, POS, Quick Add, More Tools and store expenses, plus palette, typography, icons, controls and toast references. The original files are preserved.

Include color values, typography/font files and weights, spacing, icons, reference frame dimensions, and interaction notes if available. Put production image/font assets in the project's existing assets directory when implementing.

Exports establish visual references, not screen completion or resolved business rules. See [backend-handoff.md](../backend-handoff.md#actual-moduleframe-inventory) for the code-based inventory and unresolved differences. Do not treat this README as a visual specification.
