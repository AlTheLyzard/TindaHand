# Quick Add content sizing, dragging and pickers

This follow-up supersedes the fixed-height shell and in-sheet selector in earlier Quick Add notes. It implements the user's current content-sized, draggable-sheet request. Read root AGENTS.md, current configuration and shared UI, and named workbook MA-QA-001/004/005 and KH-QA-003, including copy-sheet differences. The existing conflict over the shortcut set/Store Debt remains unresolved; this presentation task retains all three authorized forms. Requirements originals remain untouched.

## Changes

- `src/components/ui/resizable-sheet.tsx`: shared surface built around the existing MotionModal/MotionOverlay usage, tokens, IconButton and reduced-motion preference. Measures header, natural scroll-content and footer heights to show the complete standard form initially, capped at the safe-area and keyboard-adjusted viewport. Its 112×48-point handle uses core React Native PanResponder and Animated height updates, without rerendering children per drag frame or adding dependencies. The body owns its own scrolling; resize recognition is restricted to the handle.
- `src/utils/sheet.ts`: bounded content/compact/expanded heights and velocity-aware release decisions. Compact reserves space for the fixed controls and a scrollable body; coincident heights collapse safely in short viewports. A downward pull beyond compact requests dismissal. The sheet restores its selected supported height before invoking the existing close/discard flow, so Keep Editing retains a visible draft. Interrupted gestures restore a supported height. Native accessibility increment/decrement/escape actions provide alternate resize/close actions.
- `src/components/dashboard/quick-add-modal.tsx`: removes the three-option selector; each FAB option opens its chosen form. Uses the shared resizable surface for the form and for Select Customer/Select Creditor overlays in the same native modal window. The parent remains mounted and inert while a picker is active. Close/backdrop/drag/Back dismiss the picker first; selection changes only the chosen name/ID. Existing CustomerList/CreditorList retain their data, filtering, sorting and selection behavior. Picker footer actions preserve the ability to enter a new identifying name manually.
- Due Date is in the scroll body before a pinned Total Debt summary for both debt types, including customer Cash/Product. Total Debt is immediately above Save Debt and Clear. Expense retains Save Expense above Clear. Titles use existing Poppins bold at 22/33 points and reserve room for the close control. Safe-area and keyboard padding, validation, clear/save/duplicate protection, record integrations and product selection remain in place.
- `src/components/receivables/receivables-ui.tsx` and `src/components/payables/payables-ui.tsx`: optional field-activation callback used only by Quick Add to open its picker when the name input is tapped/focused. Other consumers retain their previous behavior. Manual-entry mode keeps typing available without reopening the picker on every focus.
- `tests/sheet.test.cjs`: verifies content fitting and safe-area caps, limited keyboard space, velocity-directed snaps, and dismissal thresholds.

The old selector export is no longer rendered in Quick Add; it has not been removed from shared source in case another consumer needs it. No domain/service, dependency, routing, native configuration, or requirements files changed.
