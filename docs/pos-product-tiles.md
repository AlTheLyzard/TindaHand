# POS product-card refinement

Reviewed root `AGENTS.md`, baseline MAY-ARI/KAHERA POS-001–002 acceptance criteria, the copy worksheet differences, the existing shared cart/stock guards, and the POS 1 composite alongside the Sticker Sheet palette, typography and control conventions. The latest request's selected-outline/pressed-fill distinction supersedes the composite's pale selected-card fills. The latest request also retains the English “No stock” badge.

Changes are limited to product cards:

- `src/components/pos/product-tile.tsx` is the shared card, used by `product-browsing-screen.tsx`. One accessible press target includes the whole tile and its lower-right add/quantity control, avoiding nested actions and double additions.
- The control shows `+` when absent from the cart, or that product's current quantity in a small rounded Accent Container badge. Its 48-point slot, constant border width and reserved name area prevent layout shifts. The badge follows the existing cart state, including Cart Review edits and removal; multiple digits fit within the same slot.
- Selected cards retain white surfaces and use Accent Blue outlines. Native Pressable state drives the blue pressed fill with white text, and the existing MotionSurface supplies the shared transitions and reduced-motion behavior. No scaling changes the card's dimensions.
- Zero/negative inventory stock produces a muted Surface Subtle card, Primary Disabled image placeholder and “No stock” badge. The whole target is disabled, exposes its state and quantity to accessibility services, and has a guarded handler. The existing functional cart update still enforces stock limits. Stock allocated to a cart is distinguished by “All stock selected”; inventory is never changed by selecting a card.
- `src/constants/design-tokens.json` names the Sticker Sheet's existing `#2F6CC9` color as `accentBase`. `src/i18n/en.ts` adds the card's accessible add-one hint. Navigation, payment, fixtures, shared cart logic, dependencies and native configuration are unchanged.

Verification: `npm run typecheck` and `npm run lint` pass. `node --test tests/pos.test.cjs tests/pos-checkout.test.cjs` passes all 12 tests. Headless Chrome checks actual mouse/touch presses, release outside the card, touch cancellation, single additions from either the tile or its quantity control, quantities 1/2/10, unchanged dimensions, Cart Review decrement/removal, stock-limit blocking, restored stock availability after removal, and 30 repeated attempts on a disabled zero-stock card. All pass with no console errors. Screenshots inspected against POS 1 include pressed, selected, two-digit and muted no-stock states, plus viewport checks at 320×568, 390×844 and 430×932. Ignored artifacts are in `.expo/pos-tile-check/`.

Native gesture cancellation, font scaling, VoiceOver/TalkBack and pixel matching on actual devices remain unverified. The browser build compiled for this check; no new native bundle, signed build, deployment or publication was performed for this refinement.
